# Student Record System

A simple **Student Record System developed in C++** using Turbo C++. This project allows users to enter and display basic student information such as name, roll number, age, marks, and other details.

## 📌 Features

* Enter student details
* Store student information during program execution
* Display student details
* Manage basic academic information
* Simple console-based interface

## 🛠️ Technologies Used

* **C++**
* **Turbo C++**
* Console-based application

## 📋 Student Details

The program can handle information such as:

* Student Name
* Roll Number
* Age
* Marks
* Other basic student information

## ▶️ How to Run

1. Open the source file in **Turbo C++**.
2. Compile the program.
3. Run the program.
4. Enter the required student details.
5. The entered information will be displayed on the screen.
